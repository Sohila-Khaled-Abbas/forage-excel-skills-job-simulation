## Work with the repository from Windows PowerShell

Clone the published repository once:

```powershell
git clone https://github.com/Sohila-Khaled-Abbas/forage-excel-skills-job-simulation.git
cd forage-excel-skills-job-simulation
```

After adding or updating your own learning notes and permitted evidence, publish your changes:

```powershell
git status
git add .
git commit -m "Document Excel simulation progress"
git push
```

GitHub may prompt you to authenticate through your configured Git credential manager. Do not force-push to resolve an authentication or branch-history issue.

## Add repository topics

On GitHub, open the repository page, select the gear icon beside **About**, and add the suggested topics above. Keep the description focused on the practical learning evidence.

## Before adding evidence

- Update the learning log with the date and work actually completed.
- Add only original work that you created and are allowed to share.
- Do not upload Forage's protected task files, example answers, or instructional videos.
- Remove personal information, account details, access tokens, and certificate verification codes from screenshots and files.
- Keep macro-enabled workbooks (`.xlsm`) only when they are necessary to demonstrate your own automation. Explain what each macro does and how it was tested.
- Update the README status only when the corresponding work has actually been completed.

## LinkedIn portfolio use

Once you have added meaningful practical evidence, add the repository to LinkedIn's **Projects** or **Featured** section. Describe the work as a Forage job simulation and distinguish completed exercises from learning plans or placeholders.
