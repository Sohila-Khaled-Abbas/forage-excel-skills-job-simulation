# Evidence Checklist

Check an item only after the artifact exists, has been reviewed, and is safe to share.

## Data preparation and exploration

- [ ] Notes describing the dataset structure and business context
- [ ] Data-quality observations (missing values, errors, unusual records, duplicates if applicable)
- [ ] Explanation of cleanup decisions and unresolved limitations
- [ ] Screenshot showing relevant conditional-formatting rules
- [ ] Workbook excerpt or independently reproducible example, where sharing is permitted

## Formulas and analysis

- [ ] Formula notes with example inputs and expected outputs
- [ ] Explanation of calculation logic and assumptions
- [ ] Validation or reconciliation checks
- [ ] Screenshot or workbook excerpt showing the calculations

## Charts and dashboards

- [ ] KPI definitions and intended audience
- [ ] Dashboard screenshot with sensitive information removed
- [ ] Explanation of chart choices and filters
- [ ] Three to five evidence-based observations or recommendations

## Automation

- [ ] Description of the repetitive task being automated
- [ ] VBA source code written by me, with comments
- [ ] Test cases and results, including edge cases
- [ ] Note on limitations and safe macro execution

## Final review

- [ ] Learning log updated with dates
- [ ] All links in the README checked
- [ ] No protected Forage materials or unapproved datasets included
- [ ] No personal information, secrets, or certificate verification codes exposed
- [ ] Repository status accurately reflects what has actually been completed
